CookFlow Firestore Setup (Step-by-Step)

Step 1: Create Firebase Project
1. Go to https://console.firebase.google.com/
2. Click Add project
3. Project name: CookFlow
4. Click Continue
5. Turn Google Analytics off (or on if you want), then Create project
6. Click Continue

Step 2: Create Firestore Database
1. Left menu: Firestore Database
2. Click Create database
3. Choose Start in test mode
4. Click Next
5. Choose a location, then Enable

Step 3: Create users collection
1. Click Start collection
2. Collection ID: users
3. Click Next
4. Document ID: uid_testuser
5. Add fields:
   displayName (string) = Home Chef
   email (string) = chef@example.com
   photoUrl (string) = 
   createdAt (timestamp) = now
6. Add preferences (map) with:
   diet (string) = none
   units (string) = metric
   notifications (boolean) = true
7. Click Save

Step 4: Create recipes collection
1. Click Start collection
2. Collection ID: recipes
3. Click Next
4. Document ID: Auto-ID
5. Add fields:
   ownerId (string) = uid_testuser
   title (string) = Tuscan Tomato Soup
   description (string) = A rich, creamy tomato soup.
   imageUrl (string) = https://images.unsplash.com/photo-1547592166-23ac45744acd?w=600&h=400&fit=crop
   sourceType (string) = web
   sourceUrl (string) = https://example.com/recipe
   cookTime (number) = 30
   prepTime (number) = 10
   servings (number) = 4
   difficulty (string) = Easy
   cuisine (string) = Italian
   tags (array) = soup, vegetarian
   isPublic (boolean) = false
   createdAt (timestamp) = now
   updatedAt (timestamp) = now
6. Click Save

Step 5: Add ingredients sub-collection
1. Open the recipe document you just created
2. Click Start collection
3. Collection ID: ingredients
4. Document ID: Auto-ID
5. Add fields:
   name (string) = Garlic cloves
   amount (string) = 4
   unit (string) = whole
   category (string) = produce
6. Click Save

Step 6: Add steps sub-collection
1. In the same recipe document, click Start collection
2. Collection ID: steps
3. Document ID: Auto-ID
4. Add fields:
   order (number) = 1
   instruction (string) = Sauté onions in olive oil.
   duration (number) = 5
   timerLabel (string) = Sauté veggies
5. Click Save

Step 7: Create favorites collection
1. Go back to main Firestore screen
2. Click Start collection
3. Collection ID: favorites
4. Document ID: Auto-ID
5. Add fields:
   userId (string) = uid_testuser
   recipeId (string) = paste your recipe doc ID
   createdAt (timestamp) = now
6. Click Save

Step 8: Create groceryLists collection
1. Click Start collection
2. Collection ID: groceryLists
3. Document ID: uid_testuser
4. Add fields:
   userId (string) = uid_testuser
   updatedAt (timestamp) = now
   items (array) = add one map item
5. Inside items map add:
   name (string) = Garlic cloves
   amount (string) = 4
   unit (string) = whole
   category (string) = produce
   checked (boolean) = false
6. Click Save
